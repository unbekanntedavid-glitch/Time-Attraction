# adelberger2003_fig4_digitized.json

**EN.** Numeric values digitized by us (the author of this package) from Fig. 4 of E. G. Adelberger, B. R. Heckel, A. E. Nelson, "Tests of the Gravitational Inverse-Square Law", Annu. Rev. Nucl. Part. Sci. 53, 77 (2003), doi:[10.1146/annurev.nucl.53.041002.110503](https://doi.org/10.1146/annurev.nucl.53.041002.110503); arXiv:hep-ph/0307284v1, https://arxiv.org/abs/hep-ph/0307284 (Fig. 4 on arXiv PDF p. 76; the figure is based on Fischbach & Talmadge 1999, Fig. 2.13).

- Format: list of `[log10(λ / m), |α|_95% upper bound]` pairs, read off the plotted curve.
- Status: digitized by us, reading uncertainty ≈ ±0.1 dex; context only (value ≈4×10⁻⁴ at λ = 10 km), not used in the decisive bound or in the R range.
- The figure image and the figure crop used for digitization are not redistributed (distribution rights not verified). Consult the original figure via the DOI or arXiv link.
- Read by `run_step27.py` (only this JSON file is required).

**HU.** Az általunk (a csomag szerzője által) digitalizált számértékek a fenti cikk 4. ábrájáról (arXiv PDF 76. o.; az ábra a Fischbach & Talmadge 1999 2.13. ábráján alapul).

- Formátum: `[log10(λ / m), |α| 95%-os felső korlát]` párok listája, a görbéről leolvasva.
- Státusz: általunk digitalizált, leolvasási bizonytalanság ≈ ±0,1 dex; csak kontextus (≈4×10⁻⁴ λ = 10 km-nél), a döntő határban és az R-tartományban nem szerepel.
- Az ábrát és a digitalizáláshoz használt kivágatot nem közöljük újra (a terjesztési jog nincs ellenőrizve); az eredeti ábra a DOI- vagy arXiv-hivatkozáson érhető el.
- A `run_step27.py` olvassa (csak ez a JSON-fájl szükséges).
