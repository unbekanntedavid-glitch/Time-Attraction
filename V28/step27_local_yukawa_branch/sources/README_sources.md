Data labels / Adatcímkék:
- **primary document / elsődleges dokumentum**: the original publication or report itself / maga az eredeti közlemény vagy jelentés.
- **secondary-source data (not directly verified primary data) / másodlagos forrásból vett adat (nem közvetlenül ellenőrzött elsődleges adat)**: values quoted from the original by a later paper / egy későbbi cikk által idézett értékek.
- **primary abstract text / elsődleges absztrakt**: only the abstract of the original was read / az eredetinek csak az absztraktját olvastuk.
