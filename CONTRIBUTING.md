# Contributing to Time Attraction Law

Thank you for your interest in this research. This repository documents the development of the Time Attraction Law (TAL) framework, including theoretical derivations, SPARC galaxy analysis, laboratory protocols, and interactive simulations.

Contributions are welcome in the following areas:

## Ways to contribute

### Reproduction and verification
- Run the existing Python scripts (e.g. SPARC rotation curve analysis, density-dependent coherence calculations) on your own machine and report results.
- Compare outputs against the published tables (e.g. the 10-galaxy subset or the full 175-galaxy SPARC sample).
- Document any discrepancies, including environment details (Python version, package versions, operating system).

### Data and measurements
- Independent laboratory measurements following the published protocol (atomic clock frequency shifts under controlled density/magnetic conditions).
- Additional SPARC or equivalent rotation curve datasets.
- EEG/HRV coherence measurements that can be tested against the Phi_t formulation.

### Bug reports and corrections
- Numerical errors in scripts or formulas.
- Inconsistencies between documented claims and computed outputs.
- Broken links, missing files, or unclear documentation.

### Documentation
- Clarifications to the README or laboratory protocol.
- Translations or alternative explanations of the core formulas.
- Improvements to the interactive simulator (HTML) or its documentation.

## How to contribute

1. Open an issue describing the proposed change, bug, or new measurement. Include relevant data, code output, or screenshots where possible.
2. For code or documentation changes, fork the repository and submit a pull request. Reference the related issue in the PR description.
3. For large or experimental contributions (new derivations, alternative models), open an issue first to discuss scope.
