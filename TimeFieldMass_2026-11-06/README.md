# TAL time-field mass and (λ, α_Y) exclusion: published Eöt-Wash bounds and the combined window

Version r3. Publication date: 2026-11-06.

Zenodo DOI: [10.5281/zenodo.24022021](https://doi.org/10.5281/zenodo.24022021)

This record applies published Eöt-Wash Yukawa limits as an external constraint, without a source-model fit of our own. The reduced source model did not pass genuine validation; no TAL prediction is derived from that fit. R is a conditional bound ratio, never a sigma. "Not excluded" is not confirmation.

This folder is a separate record from r2 in [`TimeFieldMass_2026-11-04/`](../TimeFieldMass_2026-11-04/) (DOI [10.5281/zenodo.23964973](https://doi.org/10.5281/zenodo.23964973)).
